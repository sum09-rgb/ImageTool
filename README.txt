IMAGETOOL WEBSITE
=================

1. Extract this ZIP file.
2. Keep the folder structure exactly as it is.
3. Open index.html in a modern browser to test locally.
4. For publishing, upload the contents of this folder to your static hosting provider (for example Cloudflare Pages).

IMPORTANT BEFORE PUBLICATION
- Replace YOUR-DOMAIN.example in robots.txt and sitemap.xml with your actual domain.
- Add a real contact email to contact/index.html.
- Review the Privacy Policy and update it for any analytics/advertising services you actually install.
- Ad spaces are reserved only. No ad scripts are included. Add provider code only after approval and keep ads separate from tool controls.
- Image files are processed locally in the browser. Large images can use substantial device memory.

FEATURES
- Separate Image Resizer and Image Compressor pages.
- Resizer supports custom width/height, aspect ratio lock, Fit/Fill/Stretch, background colour, preview and download.
- Compressor supports quality setting, optional target KB best-effort, output format, file size comparison and reduction percentage.
- Responsive dark navy/blue/white layout.
